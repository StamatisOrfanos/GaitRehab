\section{Materials and Methods}
\label{sec:materials_and_methods}
This study builds upon data previously collected in the work of Sanghan et al.~\cite{ref29}, which involved a comprehensive clinical investigation comparing the 3D 
shank kinematics of stroke patients to healthy individuals. The primary objective of this paper is to develop a machine learning–based classification framework that can 
automatically distinguish between normal and abnormal gait patterns using features extracted from the gyroscope data of that earlier study. All data processing, feature 
engineering, model design, and evaluation described herein are original contributions that aim to enhance the clinical utility of the dataset.

\subsection{Dataset Overview}
The original experiment included sixteen stroke patients and sixteen healthy individuals, all of whom walked on a flat 10-meter indoor walkway while wearing IMU sensors 
(MBIENTLAB Inc., USA) placed bilaterally on their shanks. Data acquisition protocols, participant criteria, and ethical approvals were thoroughly detailed in the original 
publication~\cite{ref29}. The recorded data consisted of tri-axial gyroscope signals sampled at 100 Hz, with angular velocities measured along the sagittal 
(x), frontal (y), and transverse (z) planes.


\subsection{Feature Extraction}
In the process of extracting features from the gyroscope data, that were located on both the shanks and thighs of the participants we focused on the z-axis angular 
velocity as it it is the most relevant to the gait cycle, since the z-axis gyroscope signals correspond to leg rotation, highly indicative of gait abnormalities.
IMU placement on the lateral shank and the use of z-axis angular velocity for gait phase identification are consistent with previous methods that demonstrated high 
accuracy in segmenting gait cycles and estimating spatio-temporal parameters~\cite{ref30},\cite{ref31}.Furthermore we decided to use the data derived from the shanks 
only, because we found that the thigh data did not provide any additional information for the task, which is also supported by the research of Hwang et al.~\cite{ref32},
who used only shank-mounted IMUs for accurate gait classification in joint impairment detection tasks.

detailed in Table~\ref{table:features}, include all major categories commonly used in gait analysis, effectively exhausting the relevant metrics for the classification task. 
It is important to note that before extracting the features, we applied a low-pass Butterworth filter with a cutoff frequency of 10Hz to the gyroscope data to remove 
high-frequency noise and ensure that the features reflect the gait patterns accurately.

\subsection{Feature Selection}
The feature selection process was conducted to identify the most relevant features for the classification task. The classification task in this case is a binary 
classification problem that enables us to use methods like Point Bi-serial Feature Selection (BFS) and Recursive Feature Elimination (RFE) to select the most
informative features. BFS evaluates the correlation between each feature and the target variable, selecting those with the highest correlation scores.

Having all the information from the feature selection algorithm we now have a subset of features, that we can use for the classification task. At this stage we
had to take into consideration the medical significance of the features, since the goal is to create a clinically applicable model that can be used in real-world 
scenarios. Based on that context we decided to focus on features that are not only statistically significant but also medically meaningful and actionable, 
like the minimum and maximum values of the z-axis angular velocity, which are directly related to the gait cycle and can be easily interpreted by clinicians. 

\subsection{Classification Models}
Although the total number of participants is 32, providing a relatively big dataset for a clinical study, it is still considered to be a small sample size. The small 
dataset size along with the modest dimensionality of the feature space, guided us to use classical machine learning models rather than deep learning 
approaches. Deep learning models typically require large volumes of training data to generalize effectively and are more prone to overfitting in small-data problems. 
On the other hand, machine learning models are well-suited for structured datasets with limited size, providing robust performance and greater interpretability. 
To evaluate classification performance, we tested a diverse set of algorithms: Logistic Regression, Random Forest, Support Vector Machines (SVM) with linear, radial 
basis function (RBF), and polynomial kernels, Extreme Gradient Boosting (XGBoost), and K-Nearest Neighbors (KNN). These models offer a mix of linear and non-linear 
decision boundaries, ensemble learning, and instance-based reasoning, enabling a comprehensive comparison across different learning paradigms.

\subsection{Evaluation Strategy}
In order to create an unbiased evaluation of model performance, we adopted a stratified k-fold cross-validation strategy. Specifically, the dataset was 
partitioned into $k=5$ folds, where each fold preserved the proportion of class labels, ensuring that both classes were adequately represented during training 
and validation. In cases like this where we have limited data, an approach like this mitigates the risk of overfitting to a particular class and provides a more 
robust estimate of generalization performance. The use of stratification is particularly important in clinical applications, where class imbalance is common 
and maintaining representative distributions during training is essential for fairness and sensitivity. All randomization procedures, including data splits and 
model seeds, were fixed using a consistent random state to ensure reproducibility of the results across different runs.
