\begin{abstract}
Accurate classification of gait abnormalities is essential for monitoring and rehabilitation for stroke patients. In this study, we present a 
lightweight machine learning framework that classifies normal versus abnormal gait signals using statistical features derived from wearable gyroscope sensors. 
Specifically, we extract statistical values from the z-axis angular velocity of both legs and evaluate multiple classifiers including logistic regression, 
support vector machines, and ensemble methods. A leave-one-out cross-validation (LOOCV) strategy is employed to maximize generalization across subjects. 
Experimental results show that several models achieve accuracy and area under the curve (AUC) values exceeding 0.95, with K-Nearest Neighbors and SVM-based 
models demonstrating nearly perfect separability (AUC = 0.99). These findings highlight the potential of minimal yet biomechanically relevant gyroscope 
features for effective gait classification in real-world healthcare settings. The proposed pipeline is computationally efficient and well-suited for deployment 
in wearable or remote monitoring systems. Future work will focus on real-time deployment of the model in embedded systems and its integration within 
gait rehabilitation platforms for continuous patient monitoring by healthcare professionals.
\end{abstract}
